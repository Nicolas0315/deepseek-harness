# 日文会话搜索索引

[English](guide.md) | 中文

## 变更

SQLite 会话查询 provider 将可丢弃的搜索索引从 schema 版本 8 升至 9。打开已识别的旧版索引时，会从会话历史重建索引，因此首次正文搜索可能耗时更长。权威会话日志、事件格式和返回文本保持不变。

日文短语现在可以匹配无空格日文正文内部，包括单字和双字查询。搜索还支持兼容假名和分解的浊音符号匹配，摘要保留原始写法。拉丁词元匹配保持不变。搜索仍通过 provider 既有的 `openAt` 配置按需启用。

## 迁移

1. 允许 provider 重建其拥有的派生索引，不要删除或重写会话日志。
2. 启动或首次搜索后，在包含 `これは日本語の文章です` 的会话中查询 `日本語`，确认结果显示原文。
3. 部署有意禁用正文搜索时，保持 `openAt: never`；此次升级不会启用该功能。
